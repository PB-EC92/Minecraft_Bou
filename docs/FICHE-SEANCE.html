Cubes 1.1-rc2 — avant la séance (Pierre seul)

Date :   Convertible replié, Firefox

A. Préparatifs, dans l'ordre

  • Exporter avec l'ancien fichier (1.0-rc ou 1.1-rc) : écran « Qui joue ? », garder le doigt 3 s sur l'engrenage (en bas à gauche) → mode parent → section « Sauvegarde » → « Exporter (fichier) ». Vérifier que cubes-sauvegarde-….json est dans Téléchargements, et le garder.
  • Remplacer cubes.html au même endroit, sous le même nom (sous Firefox, une copie ailleurs ou renommée ne retrouverait sans doute pas les mondes : non vérifié). Ne plus rouvrir l'ancien fichier : la 1.0-rc ne connaît ni le verre ni les lettres ; la 1.1-rc oublierait le temps par mot et le réglage d'appui.
  • Version : fermer tout onglet encore ouvert sur l'ancien fichier, ouvrir le nouveau, ajouter #monde=plat&graine=1 à l'adresse, Entrée (mode adresse : rien n'est enregistré). La ligne d'infos, en haut à gauche, se termine par « 1.1-rc2 ». Une adresse retouchée (mission, lecture, retour à l'accueil) recharge la page ; en cas de doute, F5.
  • Mode parent : si l'ancien fichier était la 1.0-rc, « Dernier export : jamais. » est normal. « Appui long pour vider une case » est sur « 1 s (par défaut) ».
Marteau : une découverte par profil. Ouvrir le marteau dans une partie d'enfant le retient pour ce profil, dans tous ses mondes (il ne brille plus, Pixel ne le présente plus). Tous les essais du panneau se font donc en mode adresse, où le marteau est toujours là : #monde=prairie&graine=1&mission=1&lecture=debutant (puis &lecture=autonome). Si le marteau a déjà été ouvert dans le profil d'un enfant : réimporter un export fait avant cette ouverture (mode parent → « Importer un fichier… » : tout est remplacé, réglages compris). Après tout import, rouvrir le mode parent et revérifier « Appui long pour vider une case » (un export d'une version précédente le remet à 1 s), ainsi que la nuit, les Grignotes et « Tests ».

2Barre, case ABC, boîte à lettres — #monde=plat&graine=1&mission=2&lecture=debutant

  • Portrait puis paysage : les 10 cases, le rond et les boutons ne se chevauchent pas ; la case ABC ouvre la boîte ; les 26 lettres tiennent sans défilement, assez grosses pour le doigt.

Temps par mot : déjà relevé par le jeu

Inutile de chronométrer chaque mot. Après la séance : « Qui joue ? » → engrenage (3 s) → mode parent → section « Progression » → sous le prénom de l'enfant, « Monde N, temps par mot (jeu actif) : ». Une ligne par mot : le mot (copie ou dictée), la durée, le nombre d'essais non réussis et les aides reçues ; puis « Durée de la mission 2 (les mots) : … ». Jeu actif : boîte à lettres comprise, sans le panneau de fabrication, les félicitations ni l'accueil. Monde dont la mission 2 a été finie avec une version précédente : pas de bloc « temps par mot » (ce n'est pas une panne). Monde repris en cours de mission : les mots déjà écrits sont « non relevé » et la durée est dite « partielle ». Ces relevés sont aussi dans le fichier exporté. Sortir par « Fermer sans enregistrer ».
